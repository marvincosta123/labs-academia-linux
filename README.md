### 🚀 Como rodar a Academia na sua máquina

Para rodar este portal no seu computador local, você só precisa ter o **Docker** instalado. Não é necessário configurar servidores web ou bancos de dados.

**Passo 1: Baixar os arquivos**
* Clique no botão verde **"<> Code"** aqui no topo da página do GitHub e escolha **"Download ZIP"**.
* Extraia a pasta no seu computador (por exemplo, na Área de Trabalho).
*(Se for da área e preferir usar o terminal, faça um `git clone` deste repositório).*

**Passo 2: Subir o servidor**
* Abra o terminal (Prompt de Comando, PowerShell ou Terminal do Linux/Mac) dentro da pasta que você acabou de extrair.
* Execute o comando abaixo para inicializar os contêineres:
  ```bash
  docker compose up -d
Passo 3: Acessar o Jogo

Abra o seu navegador de internet favorito e acesse:
http://localhost:8000
